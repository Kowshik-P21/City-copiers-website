# City Copiers Website 🖨️✨
> **"YOUR DOCUMENTS | OUR PRIORITY"**  
> *Trusted Printing Partner for 30+ Years*

Welcome to the official source code for the **City Copiers** customer-interactive, mobile-first website. Designed for speed, high contrast, clean typography, lead generation (Calls, WhatsApp, and Visits), and 100% free hosting on **GitHub Pages**.

---

## 🌟 Highlights & Features

- **Multi-Page Architecture:**
  - `index.html`: Hero with live hours pill, 30+ Years stats, service cards grid, rate card & binding comparison, logo philosophy (C & Keyhole security story), and testimonials.
  - `services.html`: In-depth breakdown of all 9 services (Xerox B/W & Color, Laser Printouts & DTP, Spiral/Thermal/Hardcover Binding, Lamination & 100+ Books, Machine Servicing, Equipment Sales, and Stationery).
  - `bulk.html`: High-capacity printing showcase for 100+ Books, **Strict Confidentiality Charter 🔒 for Exam Question Papers**, and Pan-India delivery details.
  - `contact.html`: Complete contact cards, 3 phone numbers, WhatsApp, Email, operating hours, interactive Google Maps embed (Opp. Hindu College Railway Station), and direct lead inquiry form.
- **Interactive Light & Dark Theme:**
  - One-click toggle in the header with persistent `localStorage` memory and smooth transition.
- **Direct Lead-Gen (No Backend Needed):**
  - Persistent floating WhatsApp chat bubble in the bottom right corner with pre-formatted greetings.
  - Instant quote request forms that format inquiry messages and launch directly into WhatsApp or email.
- **Zero-Build, Pure Static Speed:**
  - Plain HTML5, modern CSS3 (custom properties & flex/grid), and lightweight vanilla JS.
  - Loads in under 0.5s with zero external runtime dependencies.

## 🚀 How to Host on GitHub Pages (100% Free Forever)

Your repository is already connected to:
`https://github.com/Kowshik-P21/City-copiers-website.git`

### Step 1: Commit and Push the Files to GitHub

From your terminal in this folder:
```bash
git add .
git commit -m "Launch official City Copiers website with light/dark theme and interactive features"
git push -u origin main
```

*(If Git isn't installed in your terminal, you can also drag & drop the files directly into your GitHub repository on https://github.com/Kowshik-P21/City-copiers-website).*

### Step 2: Enable GitHub Pages in 3 Clicks

1. Open your repository on GitHub: [github.com/Kowshik-P21/City-copiers-website](https://github.com/Kowshik-P21/City-copiers-website)
2. Click on **Settings** (gear icon at the top).
3. In the left sidebar, click on **Pages**.
4. Under **Build and deployment > Branch**:
   - Select `main` branch.
   - Select folder `/ (root)`.
   - Click **Save**.

Within 1–2 minutes, your website will be live worldwide at:
👉 **`https://kowshik-p21.github.io/City-copiers-website/`**
